## 背景

`MusicBarOs` 是我在上海交通大学大一《工程学导论》课程中的实践项目，目标是用原生 Web 技术还原前流媒体时代专注、有仪式感的音乐播放体验。

## 方案

不同于信息流与算法推荐主导的现代音乐软件，这个项目把注意力放回「选曲—播放—控制」本身：围绕直观的曲目切换与播放状态反馈组织界面，尽量减少打扰听歌的冗余元素。

## 现状

该项目作为课程结题作品已完成并归档，源码保留在 GitHub 供查阅。
