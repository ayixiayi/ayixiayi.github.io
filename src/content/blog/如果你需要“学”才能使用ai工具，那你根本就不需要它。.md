# 引子

你会不会去盈利盈利搜“螺丝刀怎么用”，然后看评论区争论到底该握刀柄还是该握批头？会不会去小红薯发帖，标题叫“救命，螺丝刀为什么这么难用”，再看底下一群人吵成一锅粥？如果你不会，那我先恭喜你：我推测你至少是一个还算清醒的灵长类动物个体。

你第一次见到这样一个东西：下面是奇形怪状的粗塑料手柄，上面是一根不锈钢杆，顶端还有个带奇怪纹路的尖头。你大概会问：爸爸爸爸，这是什么东西啊？

不管你爸当时有没有教会你用螺丝刀，这都不是你这项技能的来源。在你用不上螺丝刀的很长一段时间里，这个技能会被你发育得不太健全的儿童大脑忘掉；等你长成一个需要用螺丝刀的悲剧成年人，在真正需要它的那一刻，你会光速学会。

# 于是

我称之为**工具悖论**：对于一件工具属性压倒一切的东西，如果你需要学习它，说明你根本就用不到它；如果你用得到它，那你根本就不需要学。

我不是说你应该连技术文档都不读，也不是说技术论坛里的人都不值一提，虽然你在那里真学到东西的概率，大概也不比在评论区学会用螺丝刀高多少。

我想说的是：如果你把安装、配置 Claude Code、OpenClaw、OpenCode 这类工具叫作“学习”，把使用它们叫作“养”，等到 OpenClaw 发布了才觉得 agent 是下一个风口，整天嚷嚷“学不完了，学不完了”，那你的人生根本就不该和这些工具有什么交集。

这类人的发言往往如此滑稽：*最近学习了很多东西，学会了怎么打开电脑，怎么使用鼠标，怎么打开浏览器，怎么连接 Wi-Fi，怎么输入字母。折腾了好几天，终于把微信装好了，我也算跟上时代潮流了。什么，QQ 是什么？时代发展太快，对普通人太不友好了。我的电脑里已经有微信这个现代科技的结晶了，比起大多数人，我已经是潮流科技大手子了，我要放过自己啦。*

这种自我感动，实在让人哭笑不得。

如果你是靠教这些人安装和使用 agent 为生的，我要把你的动机分类讨论：

1. 如果你不收钱：你完全不知道自己在干什么。我来告诉你：你是在把核弹交到根本不知道它是什么的人手里，再找一只没有变异成温斯顿的大猩猩把他带大。请不要拿你的热心危害社会。你的当务之急是打开守望先锋，开一把快速，选输出，然后玩根基去堵门。这比教不该用 agent 的人用 agent 对社会的危害更小，更能娱乐大众，还能给世界上最好玩的游戏贡献日活。
2. 如果你收钱：我想把世界上最刻薄的话都送给你。你卖的不是技术，是焦虑；你收割的也不是学费，是别人害怕被时代抛下的恐惧。

我在这篇文章里并不想展开讨论具体的技术问题：agent 的边界到底在哪里，human-in-the-loop 将来会变成什么样子。这重要吗？当然很重要。但我没有资格作为一个实际的贡献者参与到这个改变进程当中去。你恐怕也没有。

# 还有

不，我并不是什么技术阶级主义者。我为什么要支持一套自己处在最底层的阶级制度？尽管有很多人正在这么做。除了过嘴瘾，我想说的是：agent，尤其是 coding agent，需要的不是一点，不是一些，而是很多额外的知识才能运转起来。

如果你连网页版或者 App 都还用不好：新手教程都还没打通，就惦记着去冲天梯了吗？做梦去吧。

如果你已经看到了这里，那你还真是闲得没事干，而且相当能忍。给你推荐一下 omo，最近我在用这个项目。
